# Certifications professionnelles IA en France (RNCP/RS) - 2026

Jeu de donnees open data recensant les certifications professionnelles liees a l'intelligence artificielle enregistrees au Repertoire National des Certifications Professionnelles (RNCP) et au Repertoire Specifique (RS).

## Contenu

Le fichier `certifications-ia-france.csv` contient :
- Code RNCP ou RS
- Intitule de la certification
- Organisme certificateur
- Niveau de qualification (cadre europeen)
- Date d'echeance d'enregistrement
- Eligibilite CPF (oui/non)
- Eligibilite contrat de professionnalisation
- Domaine IA couvert (machine learning, data science, NLP, computer vision, IA generative)

## Sources

Donnees extraites de France Competences (franceccompetences.fr), croisees avec les fiches RNCP publiques et l'experience de BusinessDigital.fr dans la certification IA.

## Cas d'usage

- Salaries en reconversion vers les metiers de l'IA
- DRH construisant un plan de formation certifiant
- Organismes de formation souhaitant creer un parcours certifiant
